## 阅读顺序

建议先读 10.1 和 10.2，建立垂直管蒸发时从单相液体、过冷沸腾、饱和沸腾、环状流到干涸后雾状流的区域概念；再读 10.3 的垂直光管方法，理解 Chen、Shah、Gungor-Winterton 和 Steiner-Taborek 的建模差异；随后读 10.4，把水平管中的分层、间歇、环状和局部干壁纳入模型选择；最后读 10.5 和 10.6，区分实验测量边界条件和过冷流动沸腾处理。

本章与第 8 章管内冷凝、第 12 章两相流型、第 13 章两相压降和第 18 章干涸后传热直接衔接。

## 阅读顺序

建议先读 3.2，理解 A/B/C/E/F 五类壳侧流股；再读 3.3，建立壳径、管束限径、折流板切口和布管几何；随后读 3.4 和 3.5，把 Taborek/Delaware 法中的传热修正与压降修正对应起来；最后读 3.6，理解低翅片管束如何改写光管方法。

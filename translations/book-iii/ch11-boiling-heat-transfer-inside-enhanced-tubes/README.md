# 第 11 章 强化管管内沸腾传热

> **来源**：Engineering Data Book III, Chapter 11
> **PDF 页码**：307–328（22 页）
> **书内页码**：11-1 至 11-22

## 章节概览

本章描述强化管和管内插入件中的管内蒸发。涵盖垂直管和水平管两种取向，讨论的强化类型包括微翅片管、扭带插入件、波纹管和内部多孔涂层管。本章聚焦于微翅片管（工业应用最广），并给出了微翅片管和扭带插入件的预测方法。

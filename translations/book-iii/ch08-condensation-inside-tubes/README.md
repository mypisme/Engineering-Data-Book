## 阅读顺序

建议先读 8.1，建立水平管内冷凝的流型、分层、环状流和局部传热模型；再读 8.2 的微翅片管冷凝；随后读 8.3 的可凝混合物冷凝和 Silver-Bell-Ghaly 修正；最后读 8.4 和 8.5，把过热蒸汽冷却区与冷凝液过冷区从饱和冷凝区中分离。

本章与 Book II 第 3 章“冷凝传热”衔接紧密，也为 Book III 第 12 章流型图和第 13 章两相压降做准备。

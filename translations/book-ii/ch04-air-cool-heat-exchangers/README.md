## 阅读顺序

建议先读 4.1，建立高翅片 Trufin 和空气冷却器设备形态；再读 4.2，理解翅片效率、污垢和双金属接触热阻；随后读 4.3 的空气侧传热与压降；最后读 4.4 和 4.5，把热力学限制、速率限制、水力、风机和几何约束放入设计流程。若对 V<sub>face</sub>/V<sub>max</sub>、翅片效率、风机压降或初步设计交叉点不清楚，可先读 [commentary.md](./commentary.md)。

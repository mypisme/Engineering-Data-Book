# Book II 出版级复核记录

本文记录 `Engineering Data II` 第 1-5 章从“工程阅读版”进入“出版级复核”的过程。出版级复核不改变按章交付结构，重点是把可自动验证的结构问题清零，并把需要人工审校的公式、表格和例题风险显式记录。

## 复核口径

| 层级 | 检查内容 | 状态 |
|---|---|---|
| 结构完整性 | 章节入口、译文、解读、进度、资产目录齐全 | 自动检查通过 |
| 引用完整性 | 本地链接、图片、公式截图、术语锚点可访问 | 自动检查通过 |
| 数学格式 | 正文不使用行内 `$...$`；公式使用块级 LaTeX 并保留原式截图 | 自动检查通过 |
| 图表质量 | 图表为局部图表截图，放在首次说明或引用附近 | 章节进度记录已覆盖，继续抽检 |
| 公式校核 | 编号、上下标、系数、适用条件与原式截图一致 | 进行中 |
| 表格校核 | 转写表格或表格说明与原表一致 | 进行中 |
| 例题复算 | 热负荷、面积、压降、传热系数等关键数字逐行复算 | 进行中 |
| 术语符号 | 术语译名、符号含义、单位基准跨章一致 | 进行中 |

## 自动检查

脚本：

```powershell
python scripts/verify_book_ii_publication.py
```

该脚本覆盖：

- Markdown UTF-8 可读性。
- README、docs、sources、Book II、glossary 的本地链接和锚点。
- Book II 译文、解读、术语表、符号表中的行内美元数学。
- Book II 每章基础文件、源页截图数量、译文资产引用、公式 tag 编号前缀。
- glossary 术语锚点重复和符号重复风险。

# 术语表

本表按翻译过程中实际出现的术语逐步维护。译名应优先稳定，不轻易变更；确需变更时，在备注中说明原因。

| English | 中文译名 | 备注 |
|---|---|---|
| <a id="term-heat-transfer"></a>heat transfer | 传热 | 泛指热量由一处向另一处转移的过程。 |
| <a id="term-conduction"></a>conduction | 导热 | 由温度梯度引起的热传递，常见于固体或静止流体。 |
| <a id="term-convection"></a>convection | 对流换热 | 流体宏观运动和热扩散共同导致的传热。 |
| <a id="term-boiling"></a>boiling | 沸腾 | 液体向蒸汽相变并伴随传热的过程。 |
| <a id="term-condensation"></a>condensation | 冷凝 | 蒸汽向液体相变并伴随传热的过程。 |
| <a id="term-radiation"></a>radiation | 热辐射 | 通过电磁辐射进行的热量传递。 |
| <a id="term-thermal-conductivity"></a>thermal conductivity | 导热系数 | 符号通常为 `k`。 |
| <a id="term-heat-flux"></a>heat flux | 热流密度 | 单位面积上的热流率，常用 `q = Q/A`。 |
| <a id="term-fouriers-equation"></a>Fourier's equation | 傅里叶方程 | 描述导热热流与温度梯度关系的基础方程。 |
| <a id="term-film-coefficient-of-heat-transfer"></a>film coefficient of heat transfer | 膜传热系数 | 常译为表面传热系数或膜系数，需结合上下文。 |
| <a id="term-contact-resistance"></a>contact resistance | 接触热阻 | 两固体表面接触处的附加热阻。 |
| <a id="term-single-phase-flow"></a>single phase flow | 单相流 | 流体在所讨论区域中只有一个相态参与流动。 |
| <a id="term-flow-regime"></a>flow regime | 流动状态 / 流型 | 单相流中常指层流、湍流或过渡流；两相流中常指泡状、弹状、环状等空间构型。 |
| <a id="term-form-drag"></a>form drag | 形状阻力 | 由物体前后压力差引起的阻力。 |
| <a id="term-laminar-flow"></a>laminar flow | 层流 | 流体层之间主要平滑滑移，径向混合弱。 |
| <a id="term-turbulent-flow"></a>turbulent flow | 湍流 | 具有速度脉动和涡团混合的流动状态。 |
| <a id="term-reynolds-number"></a>Reynolds number | 雷诺数 | 惯性效应与黏性效应的无量纲比值。 |
| <a id="term-two-phase-flow"></a>two-phase flow | 两相流 | 两个相态同时流动，如液-气、液-汽、固-气等。 |
| <a id="term-dropwise-condensation"></a>dropwise condensation | 滴状冷凝 | 冷凝液以液滴形式附着、生长和脱离表面。 |
| <a id="term-filmwise-condensation"></a>filmwise condensation | 膜状冷凝 | 冷凝液在表面形成连续液膜，热量需穿过液膜传递。 |
| <a id="term-pool-boiling"></a>pool boiling | 池沸腾 | 液体在容器或液池中由受热表面加热汽化的沸腾过程。 |
| <a id="term-nucleate-boiling"></a>nucleate boiling | 核态沸腾 | 气泡在受热表面成核点形成并脱离的高效沸腾状态。 |
| <a id="term-film-boiling"></a>film boiling | 膜态沸腾 | 受热表面与液体之间形成稳定蒸汽膜的沸腾状态。 |
| <a id="term-emissivity"></a>emissivity | 发射率 | 表面辐射能力相对于黑体的比例，通常记为 ε。 |
| <a id="term-overall-heat-transfer-coefficient"></a>overall heat transfer coefficient | 总传热系数 | 把对流、污垢、壁面导热等串联热阻合并后的等效系数，需注明面积基准。 |
| <a id="term-fouling"></a>fouling | 污垢 / 结垢 | 传热表面运行中形成的外来沉积物或生物、腐蚀产物等附着物。 |
| <a id="term-fouling-resistance"></a>fouling resistance | 污垢热阻 | 污垢层引入的附加传热热阻，通常记为 R<sub>f</sub>。 |
| <a id="term-design-integral"></a>design integral | 设计积分 | 沿热负荷积分局部传热面积的基本换热器设计方程。 |
| <a id="term-mean-temperature-difference"></a>mean temperature difference | 平均温差 | 用于把沿程变化温差折算成等效驱动力的温差。 |
| <a id="term-log-mean-temperature-difference"></a>logarithmic mean temperature difference | 对数平均温差 | 两端温差的对数平均，常缩写为 LMTD。 |
| <a id="term-cocurrent-flow"></a>cocurrent flow | 并流 | 两股流体沿同一方向流动。 |
| <a id="term-countercurrent-flow"></a>countercurrent flow | 逆流 | 两股流体沿相反方向流动。 |
| <a id="term-shell-and-tube-heat-exchanger"></a>shell and tube heat exchanger | 管壳式换热器 | 由管束和壳体组成、两股流体分别在管侧和壳侧流动的换热器。 |
| <a id="term-controlling-resistance"></a>controlling resistance | 控制热阻 | 总热阻中占主导、基本决定总传热能力的热阻项。 |
| <a id="term-fin-efficiency"></a>fin efficiency | 翅片效率 | 真实翅片传热量与假设翅片全处于根部温度时传热量之比。 |
| <a id="term-fin-resistance-method"></a>fin resistance method | 翅片热阻法 | 用等效翅片热阻表示扩展表面传热有效性的方法。 |

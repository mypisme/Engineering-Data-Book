# 符号表

本表按翻译过程中实际出现的符号逐步维护。符号含义应结合章节语境使用。

| Symbol | 中文含义 | 备注 |
|---|---|---|
| Q | 热流率 / 单位时间传热量 | 在第 1.1 节中常表示总热流率。 |
| q | 热流密度 | 通常 q = Q/A。 |
| A | 传热面积 | 圆筒壁中局部面积为 2πrL。 |
| k | 导热系数 | 材料参数。 |
| T | 温度 | 下标表示位置或状态。 |
| T<sub>i</sub> | 内侧温度 | 具体含义随公式上下文变化。 |
| T<sub>o</sub> | 外侧温度 | 具体含义随公式上下文变化。 |
| T<sub>s</sub> | 表面温度 | 对流换热段中常表示壁面或表面温度。 |
| T<sub>f</sub> | 流体主体温度 | 原书称 volume-mean 或 mixing-cup value。 |
| T<sub>abs</sub> | 绝对温度 | 辐射公式中以 Rankine 标度表示。 |
| r<sub>i</sub> | 内半径 | 圆筒壁导热。 |
| r<sub>o</sub> | 外半径 | 圆筒壁导热。 |
| r′ | 双金属壁界面半径 | 内管外半径，同时为外管内半径。 |
| L | 管长 | 圆筒壁导热。 |
| h | 膜传热系数 | 对流换热中的工程关联量。 |
| d<sub>i</sub> | 管内径 | 雷诺数公式。 |
| V | 平均速度 | 管内流动。 |
| G | 质量速度 | G = ρV。 |
| ρ | 密度 | 雷诺数公式。 |
| μ | 动力黏度 | 雷诺数公式。 |
| Re | 雷诺数 | 无量纲。 |
| σ | Stefan-Boltzmann 常数 | 辐射公式。 |
| ε | 发射率 | 辐射公式。 |
| U | 总传热系数 | 需注明面积基准。 |
| U<sub>o</sub> | 以外表面积为基准的总传热系数 | 管壳式换热器常用。 |
| U<sub>i</sub> | 以内表面积为基准的总传热系数 | 与 U<sub>o</sub> 描述同一热流过程，但面积基准不同。 |
| R<sub>f</sub> | 污垢热阻 | R<sub>fo</sub>、R<sub>fi</sub> 分别表示外侧和内侧污垢热阻。 |
| MTD | 平均温差 | 第 1.3 节用于换热器设计方程。 |
| LMTD | 对数平均温差 | 逆流或并流理想条件下的平均温差。 |
| F | LMTD 校正因子 | 用于非纯逆流或非纯并流构型。 |
| R | MTD 图表参数 | 在图 1.29 中为两股流体温度变化范围之比。 |
| P | MTD 图表参数 | 在图 1.29 中为管侧温升或温降与最大可用温差之比。 |
| φ | 翅片效率 | 真实翅片传热量相对理想等温翅片的比例。 |
| E<sub>w</sub> | 加权翅片效率 | 同时考虑翅片面积和根部面积。 |
| R<sub>fin</sub> | 翅片热阻 | 翅片热阻法中的等效热阻。 |
| A<sub>fin</sub> | 翅片面积 | 管上所有翅片的传热面积。 |
| A<sub>root</sub> | 根部面积 | 翅片之间的光管传热面积。 |
| A<sub>eq</sub> | 等效传热面积 | 按翅片效率折减后的有效面积。 |

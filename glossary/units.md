# 单位表

本表记录原书中出现的单位及翻译说明。原书使用英制单位较多，正式计算时需另行做单位一致性检查。

| Unit | 中文说明 | 备注 |
|---|---|---|
| `microinch` | 微英寸 | 第 1.1 节用于描述金属表面粗糙度。 |
| `ft` | 英尺 | 英制长度单位。 |
| `hr` | 小时 | 英制工程单位中常用于热流率。 |
| `Btu` | 英热单位 | 原书热量单位。 |
| `°F` | 华氏度 | 原书温差和温度常用单位。 |
| `°R` | 兰氏度 | 绝对温度单位，用于辐射公式。 |
| `Btu/hr ft^2 (°R)^4` | Stefan-Boltzmann 常数对应单位 | 原书第 1.1 节采用该单位体系。 |
| `Btu/hr ft^2 °F` | 传热系数单位 | 原书用于 h 和 U。 |
| `hr ft^2 °F/Btu` | 热阻单位 | 原书用于污垢热阻和翅片热阻。 |
| `ft/sec` | 英尺每秒 | 原书速度单位。 |
| `psia` | 磅力每平方英寸绝压 | 气体和干蒸汽冲蚀速度估算式中使用。 |
| `lbm/hr` | 磅质量每小时 | 原书质量流量单位。 |
| `lbm/ft^2 hr` | 质量速度单位 | 原书用于 G。 |
| `grain/gal` | 格令每加仑 | 表 1.2 中用于描述硬水硬度。 |

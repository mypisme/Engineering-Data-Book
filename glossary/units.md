# 单位表

本表记录原书中出现的单位及翻译说明。原书使用英制单位较多，正式计算时需另行做单位一致性检查。

| Unit | 中文说明 | 备注 |
|---|---|---|
| `microinch` | 微英寸 | 第 1.1 节用于描述金属表面粗糙度。 |
| `ft` | 英尺 | 英制长度单位。 |
| `hr` | 小时 | 英制工程单位中常用于热流率。 |
| `Btu` | 英热单位 | 原书热量单位。 |
| `°F` | 华氏度 | 原书温差和温度常用单位。 |
| `°R` | 兰氏度 | 绝对温度单位，用于辐射公式。 |
| `Btu/hr ft^2 (°R)^4` | Stefan-Boltzmann 常数对应单位 | 原书第 1.1 节采用该单位体系。 |
| `Btu/hr ft^2 °F` | 传热系数单位 | 原书用于 h 和 U。 |
| `hr ft^2 °F/Btu` | 热阻单位 | 原书用于污垢热阻和翅片热阻。 |
| `ft/sec` | 英尺每秒 | 原书速度单位。 |
| `psia` | 磅力每平方英寸绝压 | 气体和干蒸汽冲蚀速度估算式中使用。 |
| `lbm/hr` | 磅质量每小时 | 原书质量流量单位。 |
| `lbm/ft^2 hr` | 质量速度单位 | 原书用于 G。 |
| `grain/gal` | 格令每加仑 | 表 1.2 中用于描述硬水硬度。 |
| `mm` | 毫米 | 第 6 章紧凑换热器管径、翅片节距、翅片厚度常用。 |
| `m` | 米 | 第 6 章例题中的管长和几何长度。 |
| `m/s` | 米每秒 | 第 6 章例题中的空气迎面速度。 |
| `kg/s` | 千克每秒 | 第 6 章例题中的质量流量。 |
| `W` | 瓦 | 第 6 章例题中的热流率。 |
| `MW` | 兆瓦 | 第 2 章地热冷凝器案例中的热负荷。 |
| `bar` | 巴 | 第 2 章地热冷凝器案例中的冷凝压力。 |
| `W/m^2 K` | 瓦每平方米开尔文 | 第 2 章表 2.1 中的传热系数单位。 |
| `m^2 K/W` | 平方米开尔文每瓦 | 第 2 章表 2.1 中的污垢系数单位。 |
| `W/(m K)` | 瓦每米开尔文 | 第 6 章例题中的导热系数。 |
| `K/W` | 开尔文每瓦 | 第 6 章例题中的传热热阻。 |
| `fins/m` | 每米翅片数 | 第 6 章例题中的翅片节距或翅片密度。 |
| `°C` | 摄氏度 | 第 6 章例题入口和出口温度。 |
